## 这个仓库是什么

全网提示词很多，能直接用在生意里的很少。这里只收录三类东西：

1. **结构好**：目标、背景、输出、规则、验收标准清楚，值得学习的范本；
2. **能落地**：外贸、国际物流、AI 一人公司、自媒体运营四条业务线可以直接拿来用；
3. **来源清楚、许可证允许**：每条都标明出处、作者和许可证，不搬运没授权的内容。

每一条都附 **Vic 点评**（为什么好）和 **改造建议**（怎么改成你自己的版本）。改造后的原创版本收录在姊妹仓库 **vic-prompts**。

## 收录标准

| 维度 | 看什么 |
|---|---|
| 清晰度 | 是否说清结果、受众、背景、交付形式 |
| 可复用 | 是否用变量（`${var}`）把会变化的部分抽出来 |
| 防翻车 | 是否有禁止编造、边界、验收标准 |
| 时效性 | 是否避免 2023 年式的“咒语”（全大写强调、强制“一步一步思考”、“检查两遍”）|
| 合规 | 来源可追溯，许可证允许转载或改编 |

评分 ≥ 7/10 才收录。卡片格式见 [templates/prompt-card.md](templates/prompt-card.md)。

## 怎么用

1. 按业务线找到提示词，复制“原文 Prompt”；
2. 把 `${变量}` 或 `[占位符]` 换成你的信息；
3. 参考“改造建议”加上你的行业背景；
4. 用得好的版本，沉淀到 vic-prompts。
